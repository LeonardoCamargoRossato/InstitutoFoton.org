# Instituto Foton documentation

This repository contains **only documentation authorized for publication**. Public documents are organized in the documentation folders below.

Operational documents, historical records, and audit records are kept **outside GitHub**, in separate institutional storage with authorized access.

A folder name does not provide confidentiality. Internal materials must not be published, even temporarily, in branches, comments, logs, or artifacts.

The [Instituto Foton portal](https://leonardocamargorossato.github.io/InstitutoFoton.org/) contains the approved institutional information.

## Folder overview

| Folder            | Short description      | Keywords                          | Detailed purpose                                                                                                         |
| ----------------- | ---------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `architecture/`   | Architecture records   | ADR, decisions, structure         | Documents architectural decisions, alternatives, consequences, and the technical structure of the static site.           |
| `audits/`         | Audit reports          | compliance, evidence, baseline    | Stores reviewed public audit reports with scope, evidence, severity, recommendations, and validation status.             |
| `content-policy/` | Content governance     | copyright, trademarks, privacy    | Defines public guidance for images, video, marks, sources, credits, permissions, and editorial responsibility.           |
| `institution/`    | Institutional overview | mission, portal, identity         | Provides the approved public institutional summary and links to the official portal.                                     |
| `lcr-overview/`   | LCR overview           | workflow, roles, governance       | Explains the public responsibilities and boundaries of the LCR Workflow without exposing private operational procedures. |
| `release-notes/`  | Public release history | changes, versions, approvals      | Records approved public changes while excluding restricted test evidence and operational security details.               |
| `security/`       | Security communication | vulnerability, privacy, reporting | Describes the public security posture and responsible reporting guidance.                                                |

## Files

- `README.md`: documentation index and folder map.

Each folder maintains its own README and direct supporting records. Private operational evidence must remain outside this public repository.
