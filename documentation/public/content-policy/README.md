# Uso de conteúdo e imagens

Textos, fotografias, vídeos, marcas e documentos do Instituto Foton devem respeitar a origem dos materiais, os direitos dos titulares e as autorizações de divulgação aplicáveis.

A disponibilidade pública de um material **não** significa autorização irrestrita para copiá-lo, modificá-lo ou utilizá-lo comercialmente. Consultas e pedidos de autorização devem utilizar os canais institucionais publicados no portal.

Esta orientação pública não substitui termos de licenciamento específicos nem avaliações jurídicas aplicáveis.
