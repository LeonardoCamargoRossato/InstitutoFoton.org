# Architecture documentation

This folder contains public architectural decision records for Instituto Foton.

## File documentation

| File                                  | Description                                                                                       |
| ------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `ADR-20261112-Portal-Estatico.md`     | Records the decision to operate the public portal as a static site and explains its consequences. |
| `20261123-arquitetura-pages-fase1.md` | Describes the first phase of the page-map and route-mirror architecture.                          |

Architecture records explain context, alternatives, decisions, and consequences. They must not contain credentials, private procedures, or sensitive operational information.
