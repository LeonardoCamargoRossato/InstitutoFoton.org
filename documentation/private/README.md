# Documentação técnica classificada como interna

**Aviso de segurança:** este repositório GitHub é público. A pasta `documentation/private/` e todos os documentos nela disponíveis **também são públicos**, inclusive via Git, API e histórico. A palavra *private* indica somente classificação documental, **não** permissão de acesso.

O conteúdo de `docs/` foi reorganizado abaixo em `docs/` para manter a estrutura visual LCR e preservar os arquivos originais. Esta movimentação não torna nenhum documento confidencial, não elimina exposição anterior e não substitui uma cópia num ambiente verdadeiramente privado.

Documentação que exija confidencialidade real deverá ser migrada mediante autorização para um repositório privado ou Google Drive institucional com permissões verificadas. Não adicione novos segredos, registros sensíveis ou documentos restritos a esta pasta.
