# Assets públicos

Esta pasta contém imagens, SVGs, documentos e outros arquivos publicados pelo site.

A organização deve seguir a página ou funcionalidade que utiliza o asset. Quando houver versões otimizadas e originais, a versão leve deve ser usada na primeira renderização e a original no visualizador ampliado.

Não colocar credenciais, arquivos privados ou conteúdo não aprovado em `public/`.
