# Testes

Esta pasta reúne os testes automatizados do projeto.

| Grupo | Função |
|---|---|
| Testes unitários | Validar funções, dados e componentes isolados |
| Testes de integração | Validar relações entre partes da aplicação |
| `browser/` | Testes E2E e auditorias visuais no navegador |

Toda alteração relevante deve preservar os testes existentes e incluir cobertura quando introduzir comportamento novo.
