# Seções de Notícias

Esta pasta contém blocos visuais exclusivos da página de notícias.

| Arquivo | Função |
|---|---|
| `NewsCarousel.tsx` | Carrossel de notícias e mídia |
| `NewsPhotoHighlights.tsx` | Destaques fotográficos |

A lógica visual reutilizável de carrossel permanece em `components/carousel`; esta pasta apenas compõe a experiência editorial de Notícias.
