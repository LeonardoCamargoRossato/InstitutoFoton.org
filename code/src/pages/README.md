## Legenda

- **Ver seção** abre a parte correspondente do site.
- **Código** abre o componente React que renderiza a seção.
- **Copy/dados** abre a fonte verdadeira dos textos e registros.
- **Assets** abre a pasta das imagens, documentos ou logos.
- **Mapa técnico** abre o `.ts` que relaciona IDs, rotas e dependências sem copiar conteúdo.
