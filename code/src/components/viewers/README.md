# Visualizadores

| Arquivo | Descrição sucinta | Descrição detalhada |
|---|---|---|
| `ImageZoomDialog.tsx` | Visualizador ampliado | Abre uma imagem em diálogo com zoom, navegação, download, créditos e suporte a tela cheia. |
| `SiteImageViewer.tsx` | Adaptador de imagens | Conecta imagens do conteúdo do site ao visualizador compartilhado quando o usuário clica ou usa o teclado. |
| `index.ts` | Ponto de entrada | Reexporta os visualizadores para uso por carrosséis e páginas sem expor a organização interna. |

Esta pasta concentra a experiência de visualizar imagens em tamanho ampliado.
