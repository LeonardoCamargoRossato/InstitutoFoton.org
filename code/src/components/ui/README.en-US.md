# Interface components

## Description

This folder contains reusable visual interface components for Instituto Foton.

## Main files

- `ActionButton.tsx`: action button with standardized styles.
- `LayoutContainer.tsx`: responsive container for organizing content.
- `README.md`: main documentation in Portuguese.
- `README.en-US.md`: English version of this documentation.

## Conventions

Components must follow the global Photon design-system tokens for color, spacing, borders, shadows, and accessibility.
