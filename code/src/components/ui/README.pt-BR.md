# Componentes de interface

## Descrição

Esta pasta reúne componentes visuais reutilizáveis da interface do Instituto Foton.

## Arquivos principais

- `ActionButton.tsx`: botão de ação com estilos padronizados.
- `LayoutContainer.tsx`: contêiner responsivo para organizar o conteúdo.
- `README.md`: documentação principal em português.
- `README.en-US.md`: versão desta documentação em inglês.

## Convenções

Os componentes devem seguir os tokens globais de cor, espaçamento, bordas, sombras e acessibilidade definidos pelo design system Photon.
