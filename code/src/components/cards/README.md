# Biblioteca de cards

| Arquivo | Descrição sucinta | Descrição detalhada |
|---|---|---|
| `index.ts` | Ponto de entrada | Reexporta os cards e os contratos públicos da biblioteca. |
| `INVENTARIO_DOS_CARDS.md` | Inventário visual | Lista os cards existentes, suas categorias e os locais onde são usados. |
| `PARAMETROS_DOS_CARDS.md` | Documentação de parâmetros | Explica propriedades, aparência, presets e regras para criar ou adaptar cards. |
| `base/` | Motor compartilhado | Reúne a estrutura, tipos, estilos e presets comuns a todos os cards. |
| `informative/` | Cards informativos | Contém cards voltados à apresentação de informação sem ação principal obrigatória. |
| `interactive/` | Cards interativos | Contém cards com clique, navegação, imagem ou ação explícita do usuário. |

As categorias especializadas reutilizam o mesmo fundamento visual definido em `base/`.
