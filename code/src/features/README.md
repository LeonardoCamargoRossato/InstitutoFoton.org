# Features

This folder contains larger functionality specific to Instituto Foton. Features combine reusable components, editorial content, and area-specific product rules.

## Folder overview

| Folder        | Short description  | Keywords                       | Detailed purpose                                                                           |
| ------------- | ------------------ | ------------------------------ | ------------------------------------------------------------------------------------------ |
| `foundation/` | Foundation feature | history, institution, timeline | Contains the page-specific foundation experience and its exclusive implementation details. |

## File documentation

This folder currently contains feature implementations and their supporting styles. Each direct module is documented by the consuming feature or page README where it is used.

Generic visual components remain in `components/`; editorial data remains in `content/`.
