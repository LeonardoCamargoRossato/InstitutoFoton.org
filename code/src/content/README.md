# Editorial content

This folder contains the data displayed by the site, separated from visual presentation.

## File documentation

| File | Description |
| --- | --- |
| `MAPA_SECOES_E_CARDS.md` | Maps editorial sections and card assignments. |
| `instituteTeam.ts` | Provides institutional team profile data. |
| `institutional.ts` | Provides institutional copy and structured content. |
| `linkedin-mockup-assets.json` | Catalogs LinkedIn mockup assets. |
| `news-media.json` | Catalogs media associated with news records. |
| `partnerAssets.ts` | Resolves approved partner assets for editorial use. |
| `partners.json` | Stores the public partner catalog. |
| `partners.ts` | Provides typed partner records and grouping data. |
| `public-documents.ts` | Provides metadata for approved public documents. |
| `publications.json` | Stores the public publication and news catalog. |
| `research-lines.json` | Stores research-line definitions and metadata. |
| `research-media.json` | Catalogs media associated with research experiences. |
| `siteCards.ts` | Provides editorial card content. |
| `siteStructure.ts` | Defines the declared site structure and navigation content. |
| `social-mockup-assets.json` | Catalogs social-media mockup assets. |
| `social-posts.json` | Stores public social-media post records. |

Editorial data belongs here; visual components belong in `components/`; larger functionality belongs in `features/`.
