# Estilos

Esta pasta reúne folhas de estilo globais e estilos específicos de áreas do site.

- `site.css`: base global da aplicação.
- Arquivos de área: regras específicas de manifesto, pesquisa, identidade, zoom e apresentações.
- `partners.css`: estilos do ecossistema de parceiros.

Novos valores visuais devem preferir os tokens em `components/foundations/tokens.css`. Exceções específicas devem ser justificadas no componente ou feature.
