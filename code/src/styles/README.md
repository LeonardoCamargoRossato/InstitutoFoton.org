# Styles

This folder contains global stylesheets and area-specific site styles.

## File documentation

| File                       | Description                                                   |
| -------------------------- | ------------------------------------------------------------- |
| `site.css`                 | Defines the global application base styles.                   |
| `home-atom-entrance.css`   | Styles the Home atom-entrance animation.                      |
| `human-editorial.css`      | Defines shared editorial typography and content presentation. |
| `image-zoom.css`           | Styles enlarged-image and zoom interactions.                  |
| `manifesto-hero.css`       | Styles the Manifesto hero presentation.                       |
| `partners.css`             | Styles the partner ecosystem presentation.                    |
| `photon-identity.css`      | Styles the Foton identity animation.                          |
| `presentation-preview.css` | Styles institutional presentation previews.                   |
| `research-journey.css`     | Styles the research journey experience.                       |

New visual values should prefer tokens from `components/foundations/tokens.css`. Specific exceptions must be justified in the consuming component or feature.
