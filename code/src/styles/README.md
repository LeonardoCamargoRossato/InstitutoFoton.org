# Styles

This folder contains global stylesheets and area-specific site styles.

- `site.css`: global application base.
- Area files: rules specific to the manifesto, research, identity, zoom, and presentations.
- `partners.css`: partner ecosystem styles.

Novos valores visuais devem preferir os tokens em `components/foundations/tokens.css`. Exceções específicas devem ser justificadas no componente ou feature.
